# LitGraph Agent

面向科研文献分析的多 Agent 智能系统前端 Demo。

该项目用于展示一个硕士毕设级别的科研文献分析平台原型：系统能够模拟论文 PDF 解析、文献证据抽取、知识图谱构建、多 Agent 协作推理、可信综述生成和审校评估流程。

## 核心功能

- 论文 PDF 上传与解析队列展示
- 规划、检索、图谱、推理、审校 5 类 Agent 协作流程
- 任务、方法、数据集、指标和结论关系的知识图谱可视化
- 自动生成带证据编号的科研综述草稿
- 引用准确性、证据覆盖率、幻觉风险和多跳推理审校
- 普通 RAG 与多 Agent 图谱增强方案的评估对比

## 技术说明

当前版本是纯前端 HTML Demo，无需安装依赖即可运行。

```bash
python -m http.server 8765 --bind 127.0.0.1
```

浏览器访问：

```text
http://127.0.0.1:8765/index.html
```

也可以直接双击 `index.html` 预览页面。

## 适用场景

- 硕士毕业设计项目展示
- AI Agent 项目申报材料
- 科研文献分析系统原型
- RAG、知识图谱、多 Agent 协作方向课程设计
